# Sunset Luxury Villas

Δίγλωσση ιστοσελίδα για το Sunset Luxury Villa στο Ακριτοχώρι Μεσσηνίας, με διαχείριση πολλών καταλυμάτων, αιτήματα κράτησης και συγχρονισμό ημερολογίων.

**Προεπισκόπηση design:** [GitHub Pages](https://kl1me.github.io/sunset-villas/).

Το πλήρες app λειτουργεί με Cloudflare Workers + D1, με frontend και API στο ίδιο HTTPS origin. **Πλήρης εφαρμογή:** [Sunset Villas](https://sunset-villas.sunset-villas-messinia.workers.dev/). Το GitHub Pages παραμένει ανεξάρτητη στατική προεπισκόπηση: δεν καλεί το backend, δεν αποθηκεύει στοιχεία επισκεπτών και δεν δέχεται αιτήματα ή πληρωμές. Ο κώδικας διατηρείται στο δημόσιο GitHub repository· τα ιδιωτικά feeds, κλειδιά και δεδομένα βάσης εξαιρούνται.

## Δομή

| Μέρος                                 | Κώδικας                       | Εκτέλεση                               |
| ------------------------------------- | ----------------------------- | -------------------------------------- |
| Δημόσια προεπισκόπηση                 | `frontend/`                   | Vite + React, GitHub Pages             |
| Πλήρες app και API                    | `app/`, `lib/`, `worker/`     | Vinext / Cloudflare Workers            |
| Βάση                                  | `db/schema.ts`, `drizzle/`    | Cloudflare D1 / SQLite                 |
| Δημοσίευση προεπισκόπησης και έλεγχοι | `.github/workflows/pages.yml` | GitHub Actions σε κάθε push στο `main` |

## Αιτήματα & διαχείριση

- Κάθε δημοσιευμένο κατάλυμα εμφανίζεται αυτόματα στο πλήρες app. Οι κωδικοί Κ1 και Κ2 χρησιμοποιούνται στην ιδιωτική διαχείριση. Το Κ2 αρχικοποιείται ως προσχέδιο μέχρι να ελεγχθούν το περιεχόμενο και οι φωτογραφίες του από τον ιδιοκτήτη.
- Η φόρμα ελέγχει στον server ημερομηνίες, χωρητικότητα, ελάχιστη διαμονή και δεσμευμένες νύχτες. Οι τιμές υπολογίζονται σε ακέραια λεπτά του ευρώ. Κενή βασική τιμή επιτρέπει εξατομικευμένη προσφορά από τον ιδιοκτήτη.
- Η δημιουργία αιτήματος δεν δεσμεύει ημερομηνίες. Επανάληψη του ίδιου αιτήματος με το ίδιο `requestKey` δεν δημιουργεί δεύτερη κράτηση. Διαφορετικό περιεχόμενο με το ίδιο κλειδί απορρίπτεται.
- Ο επισκέπτης λαμβάνει ιδιωτικό σύνδεσμο `/booking/<id>#<token>` για να βλέπει την κατάσταση και τη συμφωνημένη τιμή. Το token βρίσκεται στο URL fragment και στέλνεται στο API μόνο ως bearer header· στη βάση αποθηκεύεται το hash του. Η γνώση του κωδικού κράτησης δεν αρκεί για πρόσβαση.
- Η απάντηση της σελίδας κατάστασης δεν περιλαμβάνει όνομα επισκέπτη, email, τηλέφωνο, εσωτερική σημείωση ή κλειδιά πρόσβασης. Εμφανίζει κατάλυμα, ημερομηνίες, αριθμό επισκεπτών, ποσό και κατάσταση. Ο επισκέπτης μπορεί να αποσύρει μόνο εκκρεμές αίτημα· για επιβεβαιωμένη κράτηση επικοινωνεί με τον ιδιοκτήτη.
- Η διαχείριση περιλαμβάνει αναζήτηση, φίλτρα καταλύματος/κατάστασης, σελιδοποίηση και συνολικούς μετρητές. Ο ιδιοκτήτης ορίζει συμφωνημένο ποσό, κρατά ιδιωτική σημείωση, επιβεβαιώνει ή ακυρώνει αιτήματα.
- Πριν την επιβεβαίωση απαιτούνται συμφωνημένο ποσό και ρητός έλεγχος των πλατφορμών από τον ιδιοκτήτη. Η ατομική συναλλαγή D1 ελέγχει τις δεσμεύσεις του site, τα ενεργά εξωτερικά feeds και τα χειροκίνητα κλεισίματα. Ο μοναδικός συνδυασμός `(property_id, date)` εμποδίζει δύο επικαλυπτόμενες επιβεβαιώσεις του site. Η αναχώρηση δεν δεσμεύεται ως νύχτα.
- Η διαχείριση παρέχει `mailto:`/τηλεφωνική επικοινωνία και αντιγραφή ιδιωτικού συνδέσμου επισκέπτη. **Δεν έχει συνδεθεί υπηρεσία αυτόματης αποστολής email**· η αποστολή μηνύματος γίνεται χειροκίνητα από τον ιδιοκτήτη. Οι νέες εγγραφές εμφανίζονται με ανανέωση της διαχείρισης.

## Σύνδεση διαχειριστή & ρυθμίσεις

Το `/admin` χρησιμοποιεί το ιδιωτικό `ADMIN_TOKEN` για τη σύνδεση και δημιουργεί υπογεγραμμένη συνεδρία διάρκειας οκτώ ωρών σε `HttpOnly`, `SameSite=Strict` cookie, με `Secure` σε HTTPS. Το αρχικό κλειδί καθαρίζεται από την κατάσταση του client μετά τη σύνδεση. Η αποσύνδεση λήγει το cookie. Το API εξακολουθεί να υποστηρίζει bearer `ADMIN_TOKEN` για ελεγχόμενα scripts· δεν μπαίνει σε δημόσια αρχεία ή URLs.

Συνιστάται ανεξάρτητο `BOOKING_SECRET` για τους ιδιωτικούς συνδέσμους επισκεπτών. Χωρίς αυτό χρησιμοποιείται το `ADMIN_TOKEN`. Υπάρχοντες σύνδεσμοι επαληθεύονται με το αποθηκευμένο hash· η επανέκδοση συνδέσμου μετά από αλλαγή κλειδιού αντικαθιστά το hash.

Η εφαρμογή ξεκινά με **ενδεικτικά στοιχεία επιχείρησης και εμφανές DEMO banner**. Στις Ρυθμίσεις συμπληρώνονται πραγματικός υπεύθυνος εκμετάλλευσης, email/τηλέφωνο επικοινωνίας, επαφή απορρήτου, χρόνος διατήρησης, όροι ακυρώσεων και ώρες άφιξης/αναχώρησης. Πριν χρησιμοποιηθεί για πραγματικούς επισκέπτες, ο ιδιοκτήτης αντικαθιστά τα ενδεικτικά στοιχεία και απενεργοποιεί το `demo_mode`. Η αποθήκευση κανονικής λειτουργίας απορρίπτει εμφανώς δοκιμαστική ταυτότητα, ενδεικτικά email και ελλιπείς υποχρεωτικές ρυθμίσεις.

Η συντήρηση μετατρέπει παλιές επιβεβαιωμένες διαμονές σε `completed`, λήγει παλιά αιτήματα/προσωρινές δεσμεύσεις και αφαιρεί τις αντίστοιχες νύχτες. Αφού περάσουν οι ρυθμισμένες ημέρες από την αναχώρηση, ανωνυμοποιεί στοιχεία επικοινωνίας, σημειώσεις και κλειδιά πρόσβασης μόνο σε `completed`, `cancelled` ή `expired` εγγραφές. Ενεργές, μελλοντικές και εκκρεμείς προς έλεγχο εγγραφές δεν ανωνυμοποιούνται από αυτή τη διαδικασία. Δεν πρόκειται για έκδοση παραστατικών ή λογιστική υπηρεσία.

## Ημερολόγια

Ο αναλυτικός οδηγός είναι στο [docs/CALENDAR-SYNC.md](docs/CALENDAR-SYNC.md).

- iCal import ανά κατάλυμα για Airbnb / Booking, επιτρεπόμενα επίσημα HTTPS hosts, όριο μεγέθους/συμβάντων, timeout, απαγόρευση ακολούθησης redirects, lease ανά feed και ατομική αντικατάσταση επιτυχούς snapshot. Σε αποτυχία διατηρείται το προηγούμενο snapshot και εμφανίζεται το σφάλμα.
- Ενοποιημένο μηνιαίο ημερολόγιο, χειροκίνητα κλεισίματα και ξεχωριστή κατάσταση ανά πηγή. Η παύση feed διατηρεί το snapshot στη βάση, αλλά το εξαιρεί από τη διαθεσιμότητα και το κοινό ημερολόγιο· απαιτεί χειροκίνητο έλεγχο της αντίστοιχης πλατφόρμας.
- Το Booking Κ1 είναι η προβλεπόμενη εξαίρεση και παραμένει σε παύση μέχρι να επιλυθεί το σφάλμα export από την πλευρά της Booking. Δεν εμφανίζεται ως συγχρονισμένο.
- Το ιδιωτικό iCal export περιλαμβάνει μόνο επιβεβαιωμένες κρατήσεις, ενεργές προσωρινές δεσμεύσεις και χειροκίνητα κλεισίματα του site, χωρίς στοιχεία επισκεπτών. Δεν επανεξάγει εισαγόμενες κρατήσεις.
- Ο παραγωγικός Worker cron εκτελείται κάθε 15 λεπτά χωρίς να χρειάζεται ανοιχτός browser. Η διαχείριση εμφανίζει τον τελευταίο κύκλο ελέγχου ημερολογίων. Η κατάσταση ανά feed παραμένει ο έλεγχος για επιτυχία ή σφάλμα της συγκεκριμένης πηγής.

**Η αποθήκευση των feeds στο site δεν ρυθμίζει μόνη της τους λογαριασμούς των πλατφορμών.** Ο ιδιοκτήτης πρέπει να εισαγάγει τον τελικό ιδιωτικό σύνδεσμο iCal του site και στην Airbnb και στη Booking, ξεχωριστά για κάθε κατάλυμα. Οι υπάρχουσες συνδέσεις Airbnb–Booking διατηρούνται. Η πλήρης διαδρομή προς τις πλατφόρμες επιβεβαιώνεται μόνο μετά από αυτή τη ρύθμιση και δοκιμή δέσμευσης/ακύρωσης με τον ιδιοκτήτη.

Το iCal συγχρονίζει περιοδικά ημερομηνίες, όχι τιμές, και δεν εγγυάται αποφυγή ταυτόχρονων κρατήσεων σε διαφορετικές πλατφόρμες. Η [Airbnb αναφέρει ανανέωση ανά τρεις ώρες](https://www.airbnb.com/help/article/99). Δεν έχει συνδεθεί channel manager ή άμεσο API αποθέματος.

## Πληρωμές

**Οι πληρωμές είναι απενεργοποιημένες.** Δεν υπάρχουν κουμπιά checkout στη διαχείριση και η παρουσία παλιών test keys δεν τις ενεργοποιεί. Η παραγωγική ρύθμιση θέτει `PAYMENTS_ENABLED=disabled`.

Ο κώδικας Stripe διατηρείται για μελλοντικές δοκιμές προγραμματιστή. Μόνο ρητό `PAYMENTS_ENABLED=test`, test secret key και webhook secret επιτρέπουν αυτή τη δοκιμαστική διαδρομή. Live keys/events απορρίπτονται. Δεν έχουν ενεργοποιηθεί πραγματικές εισπράξεις, επιστροφές χρημάτων ή παραστατικά.

## Τοπική ανάπτυξη & έλεγχοι

Απαιτούνται Node.js 22.18+ ή 24 και npm.

```sh
npm ci
npm run dev:pages
```

Η στατική προεπισκόπηση ανοίγει στο `http://127.0.0.1:5173/sunset-villas/`.

Για το πλήρες app σε **νέα, κενή τοπική βάση**:

```sh
cp .env.example .dev.vars
# Ορίστε δικά σας τυχαία ADMIN_TOKEN και BOOKING_SECRET (32+ χαρακτήρες).
npm run build
for migration in drizzle/*.sql; do
  npx wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file "$migration"
done
npm run dev -- --hostname 127.0.0.1 --port 5174
```

- Site: `http://127.0.0.1:5174/` · Διαχείριση: `http://127.0.0.1:5174/admin`.
- Σε υπάρχουσα βάση εφαρμόστε μόνο τα migrations που λείπουν, με τη σειρά. Η `0003` προσθέτει τις ρυθμίσεις επιχείρησης, ασφαλή πρόσβαση/επανάληψη αιτημάτων και τη δυνατότητα παύσης feed. Μην επαναλαμβάνετε SQL που έχουν ήδη εκτελεστεί με `d1 execute`.
- Η τοπική βάση και η παραγωγική D1 είναι διαφορετικές. Τα integration fixtures εκτελούνται μόνο σε αναλώσιμη loopback εγκατάσταση.
- Για πραγματικά ιδιωτικά ημερολόγια υπάρχει [απομονωμένο τοπικό προφίλ](docs/CALENDAR-SYNC.md#ιδιωτική-τοπική-εγκατάσταση), χωρίς ανάμιξη με fixtures.

```sh
npm run typecheck
npm test
npm run build
npm run build:pages
TEST_ADMIN_TOKEN='το-τοπικό-admin-token' node tests/integration.mjs
```

Τα tests χρησιμοποιούν συνθετικά στοιχεία και feeds. Δεν στέλνουν μηνύματα ή πληρωμές και δεν περιλαμβάνουν πραγματικά credentials ή ημερολόγια του ιδιοκτήτη.

## Ανάπτυξη σε Cloudflare

Η φιλοξενία χρησιμοποιεί λογαριασμό Cloudflare του ιδιοκτήτη και δική του D1. Η δημιουργία λογαριασμού/βάσης, η εφαρμογή migrations και το επιτυχές deployment είναι ξεχωριστά βήματα. Η τελική δημόσια διεύθυνση και οι ενεργές συνδέσεις ελέγχονται μετά το deployment.

```sh
npx wrangler login
npx wrangler d1 create sunset-villas
npm run build
node scripts/prepare-cloudflare.mjs YOUR_D1_DATABASE_UUID sunset-villas
npx wrangler d1 migrations apply DB --remote --config dist/server/wrangler.production.json
npx wrangler secret put ADMIN_TOKEN --config dist/server/wrangler.production.json
npx wrangler secret put BOOKING_SECRET --config dist/server/wrangler.production.json
npx wrangler secret put SITE_ORIGIN --config dist/server/wrangler.production.json
npx wrangler deploy --config dist/server/wrangler.production.json
```

Ορίστε στο `SITE_ORIGIN` το πραγματικό HTTPS origin. Μην ξαναδημιουργείτε υπάρχουσα βάση· χρησιμοποιήστε το δικό της UUID. Το παραγόμενο production config διατηρεί τις πληρωμές κλειστές. Μετά την ανάπτυξη ελέγξτε HTTPS, σύνδεση διαχείρισης/αποσύνδεση, ιδιωτική σελίδα αιτήματος, ενεργό cron `*/15 * * * *`, heartbeat και κατάσταση κάθε feed. Η εισαγωγή των site iCal στις πλατφόρμες γίνεται κατόπιν από τον ιδιοκτήτη.

Ποτέ μην ανεβάζετε `.dev.vars`, `.wrangler`, αληθινά στοιχεία επισκεπτών, ιδιωτικούς συνδέσμους ή database dumps στο δημόσιο repository.
